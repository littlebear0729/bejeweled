# Bejeweled 3 自动玩家（Python 外挂）

通过**屏幕截图识别 + 模拟鼠标点击**自动玩电脑上的 Bejeweled 3（宝石迷阵 3），
策略上**优先制造 5 连（超立方体）**，其次 L/T 形、4 连，并把连锁反应计入评分。

## 工作原理

```
截屏(mss) → 棋盘定位(校准) → 宝石识别(HSV 颜色分类)
   → 着法搜索(枚举112种相邻交换 + 消除/下落连锁模拟)
   → 选最高分着法(5连 > L/T > 4连 > 3连，连锁指数加权)
   → 鼠标点击(ctypes) → 等待动画结束 → 循环
```

- **棋盘识别**：逐像素按 HSV 分成 7 种宝石色 + 超立方体；双帧合成抗闪光干扰
- **超立方体**：彩色环占比检测 + 静止棋盘上"仍在变色"的格子投票确认；
  识别错误的格子会被游戏拒绝并自动拉黑
- **计分权重**（内部预估分，非游戏真实分）：
  3 连=10，4 连=45，L/T 形=70+，5 连=320，6 连+=700，每层连锁 ×1.8，
  超立方体交换=150+35×全场同色数
- **自愈机制**：被游戏拒绝的着法自动屏蔽；暂停/弹窗自动按 ESC 恢复；
  单步异常自动跳过不中断

## 使用方法

```powershell
# 1. 安装依赖（一次性）
python -m pip install opencv-python mss numpy

# 2. 启动 Bejeweled 3，进入 Classic 或 Zen 模式对局（棋盘完整可见）

# 3. 首次使用先校准（窗口缩放或界面布局变化后需要重新校准）
python auto_play.py --calibrate

# 4. 开始自动玩（一直玩到按住 F8 或 Ctrl+C 停止）
python auto_play.py

# 常用参数
python auto_play.py --seconds 300      # 只玩 5 分钟
python auto_play.py --rounds 50        # 只玩 50 步
python auto_play.py --delay 0.8        # 放慢速度（更拟人）
python auto_play.py --dry              # 演练：只打印棋盘和着法，不点击
python auto_play.py --selftest         # 求解器单元自测
python auto_play.py --window "Bejeweled 3"   # 指定窗口标题
```

## 注意事项

1. **运行期间鼠标会被脚本接管**——想停止：按住 **F8** 或控制台 **Ctrl+C**
2. 游戏窗口**不要最小化或改变大小**（位置可以变，脚本每次都重新定位；
   大小变了会提示重新校准）
3. 推荐挂 **Zen（禅）模式**：永不满盘、自动洗牌，适合长时间挂机
4. 脚本会把游戏窗口自动带到前台；切走窗口游戏会自动暂停，脚本会自动恢复
5. `config.json` 保存棋盘校准结果（格子尺寸/原点），删除它即可强制重新校准

## 排错

- 提示找不到游戏窗口：先解除 Windows 锁屏，再确认游戏窗口没有最小化；
  脚本会先精确匹配标题，找不到时会回退到标题包含匹配。
- 提示截取游戏画面失败：优先使用窗口模式，并确认桌面没有处于锁屏状态。
- `--selftest` 可以单独验证求解器，不需要启动游戏。

## 项目结构

```
auto_play.py          命令行入口（含求解器自测）
config.json           校准结果（棋盘原点、格子尺寸、窗口尺寸）
bj_bot/
  winio.py            窗口交互：DPI感知、置前、截屏、点击、F8检测
  calibrate.py        棋盘自动校准（粗搜+1px精搜+双帧稳定性验证）
  board.py            宝石识别（HSV 逐像素分类 → 8x8 矩阵）
  solver.py           着法搜索（枚举交换、连锁模拟、5连优先评分）
  player.py           主循环（读盘→求解→点击→等待→循环）
```

## 调分（可选）

想更激进地追求 5 连，把 `bj_bot/solver.py` 里的 `RUN_SCORE` 中
`5: 320.0` 调大（如 `800.0`）即可；想更快点击可把 `--delay` 降到 0.2。
